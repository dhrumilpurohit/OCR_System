# 🧠 AI-Powered OCR System:

An intelligent document processing system powered by **Mistral AI** that automates document classification and data extraction using OCR. This tool helps businesses unlock insights and structure from unstructured documents like bills, invoices, and legal papers.

## 🚀 Key Features

### 1. 📄 Document Classification & Analysis
- Uses **Mistral AI's LLM** to classify documents as **normal** or **legal**.
- Extracts high-level summaries and insights using natural language understanding.

### 2. 🔍 OCR & Data Extraction
- Converts raw OCR output into clean, structured formats.
- Ideal for bills, invoices, and general documents.

## 🤖 Powered by

- **Mistral AI API** for intelligent document understanding.
- **OpenCV** for image preprocessing.
